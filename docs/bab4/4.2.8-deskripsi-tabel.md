## 4.2.8 Deskripsi Tabel (TRD)

Bagian ini merinci setiap tabel pada Gambar 4.13 (ERD) hingga ke tingkat kolom, sebagai acuan langsung implementasi migrasi basis data. Skema dipangkas hanya pada tabel yang menjadi masukan langsung modul rekomendasi (lihat catatan pada Gambar 4.13); tabel operasional KOSKITA lain berada di luar Pembatasan Masalah poin 1.

### Tabel users

Tabel 4.14 menunjukkan deskripsi tabel `users` yang terdiri dari 5 kolom. Tabel ini digunakan untuk menyimpan data akun pengguna dan admin.

| Field Name | Type | Length | Key |
|---|---|---|---|
| id | bigint | - | Primary Key |
| name | varchar | 255 | |
| email | varchar | 255 | Unique |
| password | varchar | 255 | |
| role | varchar | 255 | |
